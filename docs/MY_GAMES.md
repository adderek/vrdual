# My games

Games the maintainer owns: vrdual can be tested only on these (no need to
gift them). Per game: other ways to play it in VR, and the vrdual status
([GAMES.md](GAMES.md)).

**VR** column, from the maintainer's research (2026-10-21; may be outdated, check before relying on it):
VR-only / VR edition = a separate VR game; native VR mode = in the game itself;
mods are named. UEVR (praydog) injects VR into most Unreal Engine 4/5 games; for
any DX9/10/11 game there are also vorpX (paid) and Geo-11 / 3Dmigoto (stereo 3D
on a virtual screen), and R.E.A.L. VR (Luke Ross) covers 40+ AAA games: those
generic routes are listed only where a game-specific result was found. Empty =
nothing game-specific found yet.

**Platform** of that VR route: nearly all of them are Windows-only (SteamVR /
OpenXR, injectors); on Linux they may run through Proton with a Linux OpenXR
runtime (WiVRn, Monado; untested here). vrdual itself is Linux.
