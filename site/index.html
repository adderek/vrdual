Your 3D games, in real 3D, in VR.

vrdual renders a separate view for each eye of ordinary games, so the scene gets real depth in the headset instead of hanging there as a flat screen. No mods, no VR support needed in the game. Linux; one graphics card is enough.

Source, install and docs on GitHub · Quest 3 / 3S via WiVRn tested, any OpenXR runtime should work

How it works

  1. The game runs as usual. Vulkan, OpenGL (via Zink) and Windows games through Proton (DXVK, vkd3d). Nothing in the game changes.
  2. vrdual shifts each eye. A Vulkan layer patches the game's vertex shaders so every frame is drawn from the left eye's position and from the right eye's.
  3. The headset shows both. Each eye gets its own image: real depth, the HUD at a distance you choose, IPD and scale adjustable live.

One GPU

The eyes are rendered on alternate frames: each eye gets half the game's frame rate. Any vendor (AMD, NVIDIA, Intel). Temporal AA, upscalers and motion blur must be off.

Two GPUs

A second, identical GPU renders the other eye in parallel: each eye gets the full frame rate.

Not always the best route

vrdual works with games that know nothing about VR. A dedicated VR mod made for one game (for example witcher3-vr) can do more for that game: head tracking in the engine, motion controls, a fixed HUD. The game list names such routes where we know them.
