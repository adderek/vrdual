vrdual games

Ordinary 3D games in a VR headset with real stereo 3D, no mods, Linux. Status per game as tested; anything not listed is untested. Source and docs on GitHub.

game (Steam appid)store: testpath statussettingsnotes

works = stereo in the headset confirmed; runs = renders, stereo not confirmed or weak; broken = crash or no picture; no effect = runs, nothing to gain (2D); retest = result outdated. store: test = the store whose copy was tested and whether that test was positive. Setup, settings that break stereo and tuning: GAMES.md. Ready-made configurations for some games go to sponsors first; everything can be configured by hand, free (CONFIG.md).
