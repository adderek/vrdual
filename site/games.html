Games

Every game the maintainer owns (only these can be tested), with its vrdual status on one and two GPUs and the other VR routes for it: dedicated (a VR edition, a native VR mode, a mod for that game) and generic (by engine or graphics API). The view starts with the tested games; click one for settings, notes and wiggle GIFs.

One GPU: few games checked so far, most were tested on two GPUs. The same patch runs on one GPU with the eyes on alternate frames (half the frame rate per eye). Turn off temporal AA / upscaling (TAA, DLSS, FSR, XeSS), motion blur and frame generation: they mix the eyes.

works = stereo in the headset confirmed; runs = renders, stereo not confirmed in the headset or weak; broken = crash or no picture; no effect = runs, nothing to gain (2D); retest = result outdated. ◐ = wiggle GIF / video; ★ = tuned configuration, write-up pending; until then everything can be configured by hand (CONFIG.md). Dedicated VR: dedicated mods or tools for that game, as found; a dedicated mod usually does more for its game than vrdual. Setup and settings that break stereo: GAMES.md.

Generic routes, from the game's engine or API (PCGamingWiki data; that a route exists for the engine does not mean it works for this game): UEVR = UEVR (praydog), injector for Unreal Engine 4/5 games, per-game profiles on uevr-profiles.com; UUVR = Universal Unity VR (Raicuparta), for Unity games; vorpX = vorpX (paid), PCGamingWiki lists a profile for the game; Geo-11 = Geo-11, stereo 3D / VR screen for Direct3D 11 games.

Dedicated routes: researched by hand and from catalogs of VR mods (may be outdated, check before relying on it); PCGamingWiki marks a native VR or stereo 3D mode listed there. Nearly all of them are Windows-only (SteamVR / OpenXR); on Linux they may run through Proton with WiVRn or Monado (untested here).
