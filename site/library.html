Game library

Games the maintainer owns: only these can be tested with vrdual. Per game: which other VR routes exist, generic (by engine or graphics API) and dedicated (a VR edition, a native VR mode, a mod for that game).

Generic routes, from the game's engine or API (PCGamingWiki data; that a route exists for the engine does not mean it works for this game): UEVR = UEVR (praydog), injector for Unreal Engine 4/5 games, per-game profiles on uevr-profiles.com; UUVR = Universal Unity VR (Raicuparta), for Unity games; vorpX = vorpX (paid), PCGamingWiki lists a profile for the game; Geo-11 = Geo-11, stereo 3D / VR screen for Direct3D 11 games.

Dedicated routes: researched by hand and from catalogs of VR mods (may be outdated, check before relying on it); PCGamingWiki marks a native VR or stereo 3D mode listed there. Nearly all of them are Windows-only (SteamVR / OpenXR); on Linux they may run through Proton with WiVRn or Monado (untested here). vrdual = status in the tested games list.
